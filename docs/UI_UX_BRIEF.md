## 1. Що ми робимо (одним абзацом)

Карта Марса для планування виходу астронавта на поверхню (EVA). Користувач обирає район (Jezero / Gale), бачить підкладки NASA (рельєф MOLA, тепловий ІЧ THEMIS), шари з точками посадок, льодом і небезпеками, прокладає маршрут, який оминає круті схили, бачить профіль висот, погоду в районі (графіки температури / тиску / вологості з марсоходів) та історію місій. Кожна цифра має джерело і чесно позначені обмеження.

**Головне враження для журі за 30 секунд:** «відкрив карту → обрав район → клікнув дві точки → отримав безпечний маршрут з профілем і погодою».

## 2. Користувачі

| Персона | Що хоче | Що для неї критично |
|---|---|---|
| **Планувальник EVA** (основна) | Обрати ціль, прокласти безпечний маршрут, оцінити ризики й умови | Схили, відстань, перепад висот, небезпеки, погода, джерела даних |
| **Журі / демо-глядач** | За 30 с зрозуміти цінність | Ясна ієрархія, один «вау»-сценарій, читабельність на проєкторі 1280×720 |
| **Допитливий користувач** | Подивитися місії, лід, глобус | Глобус, картки місій, прості пояснення |

## 3. Основний сценарій (user journey)

1. **Старт** → глобальний вигляд (глобус або плоска карта) з усіма місцями посадок.
2. **Обрати район** (перемикач *Jezero — Perseverance* / *Gale — Curiosity*) → карта летить до району, видно опис сценарію і бейдж «кандидат» (рішення команди ще відкрите).
3. **Шари**: увімкнути/вимкнути небезпеки, лід, точки, змінити підкладку і прозорість.
4. **Клік по точці** (посадка / наукова ціль / небезпека / лід) → картка з даними і джерелом.
5. **Режим маршруту**: старт (за замовчуванням — база) → ціль → лінія маршруту + **профіль висот** + статистика (відстань км/милі, набір/скид висоти, макс. уклон, кількість кроків). Якщо маршрут неможливий — зрозумілий стан «недосяжно».
6. **Погода**: панель з графіками атмосфери для району.
7. **Лінійка**: виміряти відстань між двома точками (км ↔ милі).
8. **Місії**: список/таймлайн місій → картка місії → «показати на карті».
9. **Джерела**: панель «Дані та обмеження» (провенанс + дисклеймери).

## 5. Екрани та компоненти

### 5.1 Каркас головного екрана (desktop 1440 і 1280×720)

```
┌──────────────────────────────────────────────────────────────────────┐
│ ARES ▸ [Район: Jezero ▾]  [кандидат]   [Маршрут] [Лінійка] [Глобус⇄]  [Дані ⓘ] │  top bar
├──────────┬───────────────────────────────────────────────┬───────────┤
│ Шари     │                                               │ Картка /  │
│ ─ підкл. │                 КАРТА                         │ маршрут / │
│ ─ прозор.│                                               │ погода /  │
│ ─ оверлеї│                                               │ місії     │
│ Легенда  │                                     [+][-]    │ (таби)    │
│          │ 18.4447° N 77.4508° E · Mars 2000   ▭ 5 km    │           │
└──────────┴───────────────────────────────────────────────┴───────────┘
```

- Ліва панель (≈280 px) — згортається. Права панель (≈360–400 px) — контекстна з табами: **Об'єкт · Маршрут · Погода · Місії**.
- Карта займає все, що лишилось; на 1280×720 обидві панелі мають влазити без горизонтального скролу.
- Нижній рядок карти: координати під курсором (формат `18.4447° N, 77.4508° E`), масштабна лінійка (км; перемикач км/mi).

### 5.2 Панель шарів (P0)

- **Підкладка** (radio): MOLA Color Hillshade · THEMIS Day IR. Кожна — з повзунком **прозорості** 0–100 %.
- Можливість **накласти другу підкладку поверх** (напр. THEMIS над MOLA) з власною прозорістю.
- **Оверлеї** (чекбокси з кольоровою міткою і лічильником): Місця посадок · Наукові цілі · Небезпеки (схили) · Лід · Маршрут.
- **Легенда** під оверлеями: небезпеки — 2 рівні (severity 2 «обережно», 3 «виключено»); лід — «регіональний доказ», «глобальний контекст».

### 5.3 Картки об'єктів (P0) — права панель, таб «Об'єкт»

Спільне для всіх: назва, тип (іконка), координати, **рівень довіри** (`high / medium / low` — бейдж), опис, застереження (`caveat`), посилання «Джерело» (`source_ref`).

| Тип | Додаткові поля (з даних) |
|---|---|
| Місце посадки | місія, агенція, дата посадки, статус (active / ended), кнопка «Історія місії» |
| Наукова ціль | наукова мета, пріоритет, кнопка «Маршрут сюди» |
| Небезпека | вид (`steep_slope`…), severity 2/3, «обчислено з даних» (`derived`) |
| Лід | метрика, значення, оцінка глибини (якщо є) + **дисклеймер про видобуток** |

### 5.4 Режим маршруту (P0) — головна «вау»-функція

- Кнопка «Маршрут» у top bar → курсор-приціл; підказка «Клікніть ціль (старт — база)». Можна змінити старт.
- На карті: лінія маршруту (контрастна, з обводкою для читабельності на будь-якій підкладці), маркери старт/фініш, точки максимального уклону.
- У панелі «Маршрут»: **профіль висот** (вісь X — відстань, км/mi; Y — висота, м) з підсвіченими ділянками крутого схилу; статистика: відстань, набір/скид висоти, макс. уклон, середній уклон; кнопка «Скинути».
- Стани: розрахунок (спінер ≤3 с), **«недосяжно»** (немає безпечного шляху — пояснити чому), точка поза районом.
- Під профілем — дисклеймер маршруту.

### 5.5 Погода / атмосфера (P0) — таб «Погода»

Дані: `data/environment/<район>.json` — ~49 солів (марсіанських діб).

- **Графік 1 — температура повітря**: смуга min–max по солах (X — sol), опціонально лінія температури ґрунту (тільки Gale).
- **Графік 2 — тиск**: середній тиск (Па), смуга min–max — видно сезонний цикл.
- **Графік 3 — відносна вологість** (локальна, %).
- Над графіками — 3 KPI-плитки: діапазон температур, середній тиск, кількість солів; підпис станції («Perseverance / MEDA» або «Curiosity / REMS») і діапазон солів.
- Hover — тултіп з точними значеннями і часом мін/макс (LTST).
- Під графіками — застереження: точкові історичні виміри марсохода, не поточні умови.

### 5.6 Історія місій (P0) — таб «Місії»

- Список/таймлайн 12 місій (`data/missions.json`): назва, агенція, тип (lander / rover / orbiter), роки, статус-бейдж.
- Картка місії: дати (запуск, посадка, завершення), прилади (чіпи), 2 ключові результати з посиланнями, кнопка «Показати на карті» (для тих, що мають `landing_site_id`).

### 5.7 Лінійка (P0)

Клік-клік → лінія з підписом відстані (км і mi), можна кілька сегментів; Esc — вийти.

### 5.8 Глобус ⇄ плоска карта (P1)

- Перемикач у top bar. Глобус — текстура `data/textures/mars_global_2k.jpg` (2048×1024), обертання мишею, точки посадок на ньому; клік по району → перехід на плоску карту району.
- Анімація перемикання ≤ 600 мс, з повагою до `prefers-reduced-motion`.

### 5.9 Панель «Дані та обмеження» (P0)

Модальне вікно / drawer: таблиця датасетів з `data/provenance.json` (назва, місія/прилад, роздільність, дата доступу, джерело) + блок дисклеймерів. Сюди веде іконка ⓘ у top bar.

## 6. Обов'язкові тексти (дослівно, англійською — так в усіх матеріалах)

- *Mapped water-ice evidence indicates presence or likelihood, not extractability or accessibility.* — у картці льоду і легенді.
- *Absence of a mapped hazard does not mean the terrain is safe.* — у легенді небезпек і під маршрутом.
- *The route is a heuristic least-cost path on a coarse grid, not a validated traverse plan.* — під профілем маршруту.
- Дисклеймер про погоду (п. 5.5) — під графіками.

Їх не ховати в тултіпи — показувати дрібним, але читабельним текстом (≥ 12 px, контраст AA).

| Поверхня | Loading | Empty | Error | Selected / active | Focus |

| Карта / тайли | скелет + «Завантаження тайлів NASA…» | — | «Тайли Mars Trek недоступні» + повтор | — | видимий фокус на контролах |
| Шари | — | — | — | активний чекбокс + колір | ✓ |

| Маршрут | спінер | «Оберіть ціль» | «Недосяжно» / «Поза районом» | лінія + профіль | ✓ |
| Погода | скелет графіків | «Немає даних для району» | помилка + повтор | hover-тултіп | ✓ |
| Місії | скелет списку | — | помилка | обрана картка | ✓ |
| Глобус | плейсхолдер | — | fallback на плоску карту | — | ✓ |

## 8. Дизайн-система (стартові токени — Максим може змінювати, але зберегти контраст AA)

**Напрям:** «mission control, dark» — темний теплий інтерфейс, щільний, але сканований; акцент — марсіанський іржавий; статуси — чіткі. Без декоративних градієнтів, без емодзі як іконок.

| Токен | Значення | Роль |
|---|---|---|
| `--bg` | `#14100E` | фон застосунку |
| `--surface` | `#1E1714` | панелі |
| `--surface-2` | `#2A201B` | картки, hover |
| `--border` | `#3A2C25` | роздільники |
| `--text` | `#F2E8E1` | основний текст |
| `--text-muted` | `#B7A79C` | вторинний текст |
| `--accent` | `#E0703A` | основна дія, активний таб |
| `--focus` | `#FFB37A` | фокус-кільце |
| `--danger` | `#E5484D` | небезпека severity 3 / помилки |
| `--warning` | `#F2B134` | небезпека severity 2 |
| `--ice` | `#5CC8E6` | лід |
| `--science` | `#A78BFA` | наукові цілі |
| `--landing` | `#F2E8E1` | місця посадок (світлий маркер з темною обводкою) |
| `--route` | `#7CE0A3` | маршрут (з темною обводкою 2 px) |

- Контраст перевірено (WCAG): усі токени ≥ 4.5:1 на `--bg` і `--surface`. **Текст на кнопці з `--accent` — темний (`--bg`, 5.9:1)**, світлий текст на акценті не проходить (2.7:1). `--danger` як текст — лише на `--bg`/`--surface` (на `--surface-2` 4.1:1 — тільки для іконок/обводок).
- Кольори оверлеїв мають розрізнятися **ще й формою** маркера (коло / ромб / трикутник / штрихування) — для дальтоніків.
- **Шрифти** (рекомендація `ui-ux-pro-max` для дашбордів): **Fira Sans** — інтерфейс; **Fira Code** — цифри, координати, таблиці (табличні цифри). Обидва — Google Fonts. Кирилиця підтримується.
- **Шкала:** 12 / 14 / 16 / 20 / 24 / 32 px; відступи кратні 4 (4, 8, 12, 16, 24, 32).
- **Іконки:** SVG, один набір (рекомендація — Lucide, 24 px, stroke 1.5–2). Потрібні: посадка, наукова ціль, небезпека, лід, маршрут, лінійка, глобус, шари, інфо, місія (lander/rover/orbiter).
- **Графіки:** без 3D, без заливок-градієнтів; смуга min–max — напівпрозора, лінія середнього — суцільна; осі з одиницями (°C, Па, %, sol).
- **Логотип ARES** — простий wordmark + знак (за бажанням).

## 9. Доступність і адаптивність

- Контраст тексту ≥ 4.5:1, великого тексту і UI-елементів ≥ 3:1.
- Усі контроли досяжні з клавіатури; видимий фокус; `cursor: pointer` на клікабельному.
- Hover-переходи 150–300 мс; `prefers-reduced-motion` — без анімацій глобуса.
- Брейкпоінти: **1440, 1280×720 (проєктор) — основні**; 1024 / 768 / 375 — спрощено (панелі як bottom sheet).

## 11. Обмеження реалізації (щоб дизайн був реалізовним за ніч)

- Стек фронту: **HTML/CSS/JS без фреймворків**, карта — Leaflet (або аналог) у проєкції EPSG:4326, підкладки — тайли NASA Mars Trek.
- Масштаб карти району — ~25×30 км; дрібна деталізація рельєфу обмежена (~463 м на клітинку): не обіцяти «кожен камінь».
- Дані — статичні JSON/GeoJSON з гілки `data`; погода — історична, не «live».

## 12. Відкриті питання (не блокують дизайн)

- Остаточний район / сценарій (зараз Jezero за замовчуванням).
- Поріг уклону для пішого маршруту (пропозиція 15°).
- Чи повертаємо індекс 0–100 — якщо так, окреме ТЗ.
- Домен / хостинг.
